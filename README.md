# ✦ AI Chat

A premium, responsive AI chat interface inspired by modern productivity apps.

## Features

- Responsive desktop and mobile UI
- Conversation history with localStorage persistence
- New chat and clear history controls
- Dark/light theme
- Quick prompt suggestions
- Typing state and polished micro-interactions
- No API key exposed in the browser

## Run

No build step is required. Open `index.html` in a browser or deploy the repository to GitHub Pages, Netlify, or Vercel.

## Connect a real AI model

The current project includes a client-side demo response so it works immediately. For production, add a server-side `/api/chat` endpoint and call your AI provider there. Keep API credentials in server environment variables and never commit secrets.

## Stack

HTML · CSS · JavaScript · LocalStorage
